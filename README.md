# Panic Pack!

A first-person "beat the clock" game. Your taxi is coming — search the house, grab everything on your randomized packing list before time runs out, then get out the front door.

## Download

**[Download the latest build (Windows)](https://github.com/hamzaaaaaf/panic-pack-/releases/tag/v0.1.0)**

Unzip and run `PanicPack.exe` (keep `PanicPack.pck` next to it).

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| E | Interact / pick up / drop |
| Tab | Hold to view packing list |
| Space | Jump |

## Built with

Godot 4.7
